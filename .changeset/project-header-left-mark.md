Line up every project name in the spaces sidebar. Each project header keeps the agent mark slot at
its start, and shows its main space's mark there only while that space is working, blocked, or done.
A header without a main checkout draws its name in a muted tone. Both kinds of header now end with
the hidden count, the age, and then the fold chevron, which shows on hover while the project is
open. A thin line in the selected color now separates the projects.
