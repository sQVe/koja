'koja': minor
---

Add Koja's UI foundation to the kit: named text roles (view title, title, body, section heading,
detail, and badge) in Regular and SemiBold only, a state line for empty, loading, and error states
with an optional button or key hint, and a `circle-alert` icon. Small buttons inside rows grow from
14 to 16 px, key hints draw at 11 px, and repository names in the sidebar draw in SemiBold instead
of Bold. The light theme gets darker text, accent, and status colors so text and status marks are
easier to read. The Mock scenes mod gains the `states`, `popup`, and `controls` scenes, and the
`sidebar` scene now matches the live sidebar.
