Add Koja's first mods: the spaces sidebar, the tab bar, the Go to picker, the command palette, the
context menu, and the + menu, ported from the Herdr setup and drawn through one UI kit. A kit
gallery shows every component. `bun run herdr:install` installs the mods, keys, settings, layout,
and theme into Herdr's home as real files, and `bun run herdr:watch` installs on every save.
