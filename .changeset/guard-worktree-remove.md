Ask for a worktree remove only once its risks are known. Remove names uncommitted changes and a
running agent together, re-reads the risk before Grove runs and the live agent before it closes the
space, and claims Herdr's close confirmation only for the set it showed. `--force` needs a confirmed
change loss, so an agent-only warning leaves Grove's own guards on. Escape or a host close stops
every command and check that would follow, including a space open or close. A Grove process that
already started is not stopped. A branch or worktree name that starts with `-` is refused, and a new
worktree whose folder Git does not list offers a lookup-only retry.
