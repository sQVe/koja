Add Koja's own normal mode. `ctrl-b` opens an invisible `koja-modal` overlay that holds the
keyboard, and the Neovim key table drives panes, tabs, spaces, agents, the palette, and the picker.
Normal mode stays open after a command, `i`, `a`, and `Enter` return to the pane, and the
`koja-tabs` mode dot shows while it is open. It replaces the personal `modal` and `modal-pill` mods.
